想要「真·电脑 UA」？看这里（进阶）
网页内部的 UA 已被改写，但请求头仍由公共代理发出。若站点仍返回手机版，可自建一个代理（Cloudflare Worker，免费）， 它就是一台真正的电脑在替你访问： 
export default {
  async fetch(req){
    const u = new URL(req.url).searchParams.get('url');
    if(!u) return new Response('need ?url=');
    const r = await fetch(u, {
      headers: {
        'User-Agent':'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/141.0.0.0 Safari/537.36',
        'Accept-Language':'zh-CN,zh;q=0.9'
      }
    });
    const body = await r.text();
    const h = new Headers(r.headers);
    h.set('Access-Control-Allow-Origin','*');
    h.delete('X-Frame-Options'); h.delete('Content-Security-Policy');
    return new Response(body,{status:r.status,headers:h});
  }
}
部署后把「公共代理」选为「自定义代理」，前缀填 https://你的域名/?url=。
